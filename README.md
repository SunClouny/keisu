# 数読みダービー（かずよみダービー）
合言葉で集まる2〜10人用の数字予想ゲーム。各プレイヤーが表示名とラウンドごとのBETを決めます。
## GitHub Pages 公開手順
このZIPを展開し、中のファイルを新規リポジトリのルートに配置してください。Settings → Pages → Deploy from a branch で main の /(root) を選択します。
公開URLを開くとオンライン対戦、同じURLの scorebook/ を開くと1台で遊ぶ記録画面になります。
## 質問モード
部屋を作るときに、1分の制限時間モードかチャットモードを選べます。チャットモードでは子1人あたりの質問回数を1〜20回で設定し、全員に同じ回数を適用します。対戦開始時に決まった順番を使い、そのラウンドの親の次の人から1問ずつ交代します。親が答えると次の子の番です。全員が質問を使い切り、親の回答が終わると予想を確定できます。親は何回でも嘘を記録できます。嘘は精算後に公開されます。
## 共有データ
オンライン画面は公開稼働中の https://keisu-rooms-yusuke.yutan226.chatgpt.site/api/rooms に接続します。GitHubに部屋の合言葉やプレイ記録をコミットする必要はありません。部屋の利用期限は作成から24時間です。
## 設定とルール
推奨初期値は300点、標準BETは10点。新しい部屋では賭け点を10点から100点まで、10点刻みで選びます。標準BETも同じ10通りから選べます。親の回数の初期値は1人2回で、1〜20回に変更できます。対戦開始時に参加者の順番をランダムに決め、その順に親を担当します。ラウンドごとに587種類の身近な普通名詞から9種類を抽選し、1〜9に重複なく割り当てます。基本オッズもラウンドごとに抽選します。予想中は基本オッズを表示し、全員の予想確定後に人数を反映したオッズを公開します。タイマー対戦は1分後に予想を確定できます。チャットでは、嘘と「わからない」1回につき0.5倍（合計5倍まで）を、人数で割った基本オッズに足します。その倍率に賭け点を掛け、選んだ数字の個数で割り、最後に端数を切り捨てます。「わからない」と答えた場合、質問した子は、その回答で増えた親の支払いと同額をほかの子に分けます。2人対戦では質問した子の点数から引きます。
## テスト
Node.js 22以降で node --test を実行してください。worker/ に共有サーバーのゲーム処理、tests/ にテストがあります。
